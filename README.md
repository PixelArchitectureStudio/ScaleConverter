# Scale Converter

Scale Converter is a lightweight application for converting dimensions between architectural scales.

Select the real-world unit, drawing unit, and target scale, then enter a value to calculate the converted result.

## Features

* Minimal and user-friendly interface
* Dark Mode and Light Mode support
* Persian and English languages
* Offline Windows version
* Android version
* Progressive Web App (PWA) for iOS

## Available On

* Web
* Windows
* Android
* iOS (PWA)

## How to Use

1. Select the real-world unit
2. Select the drawing unit
3. Choose the target scale
4. Enter the value
5. View the result

## Built For

Architects, designers, students, and anyone working with scaled drawings.
